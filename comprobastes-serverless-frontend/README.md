# Nubixia web
Frontend Angular. Consulta el README.md de la carpeta raíz para ejecutar el proyecto completo, la API y el despliegue AWS.
`npm ci`, `npm start`, `npm run build`, `npm test -- --watch=false`.
La URL de la API se puede configurar en public/config.json o desde la pantalla Conexión API. No guardar credenciales en ese archivo.
